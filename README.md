# weather-dashboard

Mi primer mini proyecto para mi portafolio: un buscador de clima simple hecho
con HTML, CSS y JavaScript puro, consumiendo la API de OpenWeatherMap.

## Qué hace

Escribes el nombre de una ciudad y muestra la temperatura actual, la
descripción del clima, la sensación térmica y la humedad.

## Cómo correrlo

1. Clona este repositorio
2. Obtén una API key gratuita en [openweathermap.org](https://openweathermap.org/api)
3. Pega tu API key en `script.js`, en la constante `API_KEY`
4. Abre `index.html` en tu navegador

## Qué aprendí

Mi primer proyecto completo construyendo desde cero: estructura con HTML,
estilo con CSS y lógica con JavaScript, además de mi primera vez consumiendo
una API externa con `fetch()`.

## Tecnologías

HTML · CSS · JavaScript (fetch API)
